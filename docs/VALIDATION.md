# Проверка готового проекта

Все изменения и инструменты находятся внутри `/home/artur/asia`.

## Учебный источник

- Прочитаны визуально все 3 страницы оригинального «Азия.pdf».
- Повторно сверены 48 строк и 288 учебных ячеек до начала разработки.
- Excel в исходном проекте отсутствует; использован PDF согласно приоритетному указанию.
- `npm run verify:data` проходит: хеш PDF, транскрипция, рабочий JSON, номера страниц/строк, 48 ID карты, непустые SVG-пути и координаты маркеров.

## Автоматические проверки

- `npm run lint`: ошибок и предупреждений нет.
- `npm run test`: **39 тестов прошли** (30 — данные и игровая логика, 9 — хранение).
- `npm run build`: строгая проверка TypeScript и production-сборка прошли без ошибок и предупреждений о размере модулей.
- `npm run test:e2e`: **17 сценариев прошли**; один сценарий жестов пропущен в профиле компьютера и успешно выполнен в профиле телефона.

Браузерные проверки включают реальные нажатия на все 48 стран в обоих профилях (мелкие территории телефона — с увеличением региона), скрытие ответов и баллов в экзамене, индивидуальные баллы, восстановление проверенного задания после перезагрузки, повтор ошибочных полей, повтор того же набора, фильтры справочника, темы, звук как настройку, подтверждение сброса, клавиатуру, Escape в развёрнутой карте, перетаскивание, жест двумя пальцами и нажатие пальцем на маркер.

Проверено отсутствие горизонтального переполнения страниц при ширинах 320, 390, 768 и 1440 пикселей. Автоматические проверки axe-core по WCAG A/AA не выявили нарушений на главной, в игре до/после проверки, в результатах и справочнике — в обеих темах и обоих профилях. Автоматический аудит не является полной сертификацией доступности.

Собранная версия проверена через `npm run preview`:

- Нет ошибок JavaScript и запросов к внешним сервисам.
- Полностью правильный ответ дал 6/6, 100% и оценку 5.
- После отключения сети в уже загруженной странице работают справочник, поиск и новая тренировка с локальной картой.

## Переносимая версия для Windows

Обычный `index.html` и `dist/index.html` воспроизводимо не запускают приложение при прямом открытии через `file://`: не загружаются отдельные скрипты и стили. Для передачи подготовлены самостоятельный `Азия.html` и `Asia-Windows.zip`. Приложение, карта, шрифты и данные встроены в один HTML. В архив добавлена короткая инструкция в UTF-8.

- `npm run build:portable` проходит; HTML занимает около 930 KiB.
- `npm run test:portable`: 5 сценариев проходят в Chromium без сервера, с отключённой сетью.
- Проверены все 48 строк справочника и их характеристики, выбор всех 48 стран на карте, масштабирование, полноэкранный вид, оценивание, экзамен, сохранение темы/ответов/статистики после перезагрузки.
- Отдельная проверка переносит только HTML в папку с пробелами и кириллицей; полный правильный ответ даёт 100%.
- Нет дополнительных запросов к соседним файлам или сети.
- Проверены целостность ZIP и совпадение вложенного HTML с готовым файлом.
- Линтер, 39 unit-тестов и сверка учебного источника продолжают проходить.

Проверка выполнена на Linux в Chromium (движок Chrome и Edge). Настоящая Windows в этой среде недоступна; запуск на Windows не заявляется как выполненный. Для одноклассника: распаковать архив, открыть `Азия.html` в Microsoft Edge или Google Chrome.
