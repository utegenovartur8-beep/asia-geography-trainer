# Азия: географический тренажёр

Готовый школьный тренажёр для 48 стран из «Азия.pdf». React + TypeScript + Vite. Сервер, база данных и внешние API не нужны. Карта и шрифты поставляются вместе с приложением.

## Для одноклассника на Windows: открыть без установки

Передай **`Asia-Windows.zip`**. Его нужно скачать, распаковать в обычную папку и открыть **`Азия.html`** двойным щелчком в Microsoft Edge или Google Chrome. Если HTML открылся в редакторе, выбрать «Открыть с помощью» → браузер. Не запускать через предпросмотр мессенджера.

Можно передать один `Азия.html`: внутри него находятся приложение, карта, учебные данные, стили и шрифты. Интернет, Node.js, Python и терминал не нужны. Для сохранения истории открывай тот же файл из той же папки тем же браузером.

Это отдельная переносимая сборка. Исходный `index.html` и обычный `dist/index.html` требуют запуска через Vite или статический хостинг и не предназначены для двойного щелчка.

Создать переносимую версию заново:

```bash
npm run build:portable
npm run test:portable
```

Команда создаёт `portable/index.html`, копию `Азия.html` и архив `Asia-Windows.zip` с инструкцией. Сборка воспроизводится и на Windows с установленным Node.js. Проверка запускает браузер напрямую через `file://` с отключённой сетью, без сервера.

Прямое открытие проверено в Chromium, включая отдельную папку с пробелами и кириллицей, все 48 стран, ответы, экзамен и сохранение после перезагрузки. Самой Windows в этой среде нет; проверка не является запуском на настоящей Windows.

## Разработка на Windows

Установи Node.js 22 или новее, открой терминал в папке проекта и выполни:

```powershell
npm.cmd install
npm.cmd run dev
```

В браузере открой напечатанный адрес, обычно http://localhost:5173. Для сборки — `npm.cmd run build`, для тестов — `npm.cmd run test`. Файл `scripts/use-local-node.sh` и папка `.tools` с Linux-версией Node.js относятся только к этой рабочей среде и на Windows не нужны. `npm.cmd` позволяет обойти выбор PowerShell-скрипта `npm.ps1`, не меняя политику выполнения скриптов.

## Запуск

Нужен Node.js 22 или новее.

```bash
npm install
npm run dev
```

Открой адрес, который напечатает Vite (обычно http://localhost:5173).

В этой рабочей среде Node.js был установлен **внутри проекта**, в `.tools`, поскольку системного Node.js нет. В новом терминале сначала выполни:

```bash
cd ~/asia
source scripts/use-local-node.sh
npm run dev
```

Скрипт использует локальный Node.js, если он есть, и задаёт папки кеша и временных файлов внутри проекта. На компьютере с установленным Node.js этот шаг не требуется.

## Проверки и публикация

```bash
npm run lint
npm run test
npm run build
npm run preview
```

`npm run test` запускает тесты генерации вариантов, проверки ответов, подсчёта баллов, работы над ошибками и хранения прогресса. `npm run build` сначала создаёт SVG-представление из локального GeoJSON, затем проверяет TypeScript и собирает приложение в `dist/`.

Для браузерных тестов:

```bash
source scripts/use-local-node.sh
npx playwright install chromium
npm run test:e2e
```

Тесты выполняются в Chromium в профилях компьютера и телефона. Они проверяют фактическое нажатие на каждую из 48 стран, экзамен без промежуточных подсказок, восстановление тренировок, ошибки, повтор, фильтры, темы, жест двумя пальцами, сброс статистики и доступность с axe-core. На телефоне для мелких территорий используются кнопки увеличения регионов. Сценарий жестов выполняется только в профиле телефона.

Дополнительная сверка источника (Python 3):

```bash
npm run verify:data
```

Для статической публикации загрузи **содержимое `dist/`** на любой статический хостинг. Относительные пути позволяют разместить сайт и в подпапке. Обычная папка `dist/` открывается через `npm run preview` или статический хостинг. Для двойного щелчка через `file://` предназначен отдельный файл `Азия.html` из переносимой сборки. Приложение обращается только к собственным файлам сайта; после загрузки обучение не требует внешних сервисов.

## Учебные данные

В исходном проекте найден только `Азия.pdf`; Excel отсутствует. PDF имеет приоритет согласно первому указанию пользователя. Прочитаны все 3 растровые страницы и вручную повторно сверены все 48 строк и 6 учебных столбцов. Интернет использовался только для геометрии карты и инструментов, а не для исправления учебных ответов.

- [Исходная транскрипция](source/transcription.tsv): все строки по порядку PDF.
- [Рабочий JSON](src/data/countries.json): буквальные значения, ID карты, страница и номер строки источника.
- [Протокол сверки](source/AUDIT.md): контрольные итоги, особенности формулировок и технические соответствия карты.

В таблице нет пропусков и прочерков. Модель поддерживает `null`: такие характеристики не включаются в задания и не влияют на баллы. Пояснения в скобках и составные категории сохранены полностью; ответы должны соответствовать полной формулировке ячейки. Колониальное прошлое проверяется как одно значение, включая страну-колонизатора.

## Как пользоваться

- **Обучение**: без ограничения времени; правильные ответы и краткая карточка после проверки.
- **Экзамен**: 10, 20 или все страны; разбор, оценка, баллы и серия только после завершения. Время не ограничено.
- **Работа над ошибками**: только страны и характеристики с ошибками в завершённых попытках. Правильный ответ убирает характеристику из списка повторения.
- **Случайная страна**: одна страна в выбранном режиме и с выбранными типами заданий.
- **Только характеристики** включает столицу и остальные характеристики без карты.
- **Тот же набор** сохраняет порядок стран и набор проверяемых характеристик; варианты перемешиваются снова.

За каждый ответ — отдельный балл. Серия — число полностью верных стран подряд. Оценка: от 90% — 5, от 75% — 4, от 50% — 3, ниже 50% — 2. Если оставить поле без ответа и нажать «Проверить», оно считается ошибкой. В экзамене проверка обозначена «Сохранить ответ».

Карта не показывает названия до проверки. Выбор территории не сообщает её название. Для маленьких стран предусмотрены маркеры и увеличение регионов; в увеличенном виде область нажатия на маркер имеет диаметр 40 экранных пикселей. SVG поддерживает масштабирование колесом, двумя пальцами и кнопками, а также перетаскивание и разворот на весь экран.

Клавиатура: Tab — переход; Enter / пробел — выбор; Ctrl + Enter (или ⌘ + Enter) — проверка / следующее задание. На карте: стрелки — перемещение, + / − — масштаб, Home — сброс, Escape — выход из развёрнутого вида.

История, настройки, ошибки и незавершённая тренировка хранятся в `localStorage` этого браузера. Сброс требует подтверждения. История не переносится автоматически на другой браузер. Звук по умолчанию отключён; включается в шапке. Анимации учитывают системную настройку уменьшения движения.

## Структура

```text
src/
  components/    главная, игра, карта, атлас, результаты, статистика, диалоги
  data/          страны, GeoJSON, координаты маркеров, производные SVG-пути
  lib/           генерация, проверка, подсчёт, хранение, звук, названия режимов
  App.tsx        навигация и состояние приложения
  main.tsx       точка входа и обработка ошибок
  styles.css     адаптивный дизайн, темы и анимации
source/          транскрипция и протокол сверки PDF
scripts/         проверка источника, генерация карты, локальная среда Node.js
tests/           unit-тесты и браузерные сценарии
public/          значок приложения
dist/            обычная сборка для статического хостинга
portable/        переносимая сборка в одном HTML
Азия.html        готовый файл для прямого открытия в браузере
Asia-Windows.zip архив для передачи однокласснику
Азия.pdf         оригинальный источник
```

Карта: [Natural Earth, 1:50m](https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_50m_admin_0_countries.geojson), public domain. GeoJSON сохранён локально; SVG генерируется детерминированно, сохраняя геометрию всех изучаемых стран. Фон упрощается для меньшего объёма загрузки. Шрифт Manrope поставляется локально через Fontsource (OFL). Значки — Lucide (ISC). Звуки синтезируются Web Audio API.
